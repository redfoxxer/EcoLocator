# EcoLocator
A personal carbon footprint log for users to track daily carbon emissions with visual data representations.

## 📌 Features
- **Data Logging:** Track daily transportation, energy consumption, and lifestyle activities.
- **SQL Database Integration:** Store user inputs using a custom MySQL database schema.
- **Data Visualization:** Generate charts to analyze emissions over time.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Database:** MySQL
- **Libraries:** Matplotlib, Pandas, MySQL Connector

### Prerequisites
- Python installed
- MySQL Server running
